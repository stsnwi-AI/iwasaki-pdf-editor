# 書き込むボタンとツール開閉（Ver.3.5.3）

main b772ae99520d1ab4dd2cbeb01788bb80ff302558を基準に変更。

スマホ・タッチ端末では「書き込む」を押すと編集モードに入り、書き込みツール・色・文字入力・修正欄が開く。もう一度押すか「見る・動かす」を押すと閲覧に戻り、ツールを閉じて選択を解除する。別の「ツールを表示」ボタンは削除。aria-pressed/aria-expandedもモードと同期する。

選択した文字の修正やツール選択も同じモード切替を使う。削除確定後は既存の閲覧復帰と同時にツールを閉じる。「元に戻す」はツールを閉じた後も使えるようページ編集の隣へ移す。PCの通常のツール表示は維持する。

版表示・資産クエリ・PWAキャッシュを3.5.3に更新。構文チェックと既存の回帰テスト成功。390pxタッチ環境で初期非表示、書き込むのオン/オフ、見る・動かすで閉じる動作、アクセシビリティ状態、削除確認・Undo・PDF保存/復元・共有・オフライン読込を検証。実機は未検証。
