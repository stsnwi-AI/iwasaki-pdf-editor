# Ver.3.5.1の削除操作を修正欄へ統合

基準：main `7e093e5f62735c55a57ac0134e91d3db90353b83`。ユーザー提供ZIPのVer.3.5.1をもとに、ユーザー指定の操作へ変更する。

- 書き込みツールの名前を「選択・移動・削除」に変更。選択した対象を移動・修正し、同じ修正欄内の「削除」で削除する。ツールや対象を押すだけでは削除しない。
- 独立した「選択した書き込みを削除」ボタンを修正欄へ移動し、PDF上部のタッチ操作欄から重複する削除ボタンを除去。削除ボタンは1か所とする（PCの右クリックメニューは維持）。
- 提供ZIPの誤削除対策を取り込み、スマホでは確認・取消、対象ページとオブジェクト参照の検証、1件のみ削除、削除後の閲覧復帰、再確定で追加削除しない動作を維持。PCの削除は従来どおり即時実行する。
- Delete/Backspaceで確認前に削除済みと表示していた案内を除去。
- 画面表示、資産クエリ、PWAキャッシュを3.5.1に統一。ZIPの.nojekyllは公開設定に関わるため今回追加しない。vendor・PDFデータ形式は変更しない。

構文チェックとChromiumの回帰テストで、PC削除・Undo、スマホの独立削除ボタン不在・ツール名・確認取消・確定・再確定・Undo、PDFの保存/再保存/復元・共有PDF・オフライン読込を検証する。iOS/Android実機とネイティブ共有は未実施。

作業ブランチとDraft PRで提示し、mainへのマージ・公開は行わない。
