# 書き込み修正欄の配置（Ver.3.5.2）

基準main：2374450847c81365615a4f9f121e5cedd5915800。

選択中の種類を「書き込みを修正」の見出し横へ移動し、移動・サイズ変更と回転の案内をアイコン付きの2段カードとして修正欄に集約。コピー・複製・貼付け等も同じ欄に2列で配置し、削除は最下部に置く。倍率表示の下には選択・回転の操作説明を表示しない。処理結果やエラーの通知は従来のstatusに残す。

未選択でもPDFを開いていれば修正欄を保持し、選択を促す表示とクリップボード操作を残す。対象がないときは文字・線幅・操作説明・削除を隠す。スマホではツールを表示したときに修正欄を表示する。

構文チェック、既存のPDF保存・再保存・復元・削除確認・取消・Undo・共有・オフラインの回帰テストを実施。390pxのスマホ画面で選択表示・操作説明・操作ボタンが修正欄内にあり、横にはみ出さないことを確認し、スクリーンショットを目視確認。iOS/Android実機は未確認。

表示・資産クエリ・キャッシュは3.5.2で統一。PDF形式、vendor、削除の確認フローは変更しない。作業ブランチとPRで提示する。
