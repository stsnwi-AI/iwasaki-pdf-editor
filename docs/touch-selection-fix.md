# 修正中に書き込みが消えたように見える問題

PR #4への追加修正。390pxタッチ環境で選択直後に修正欄が広がり、PDFが約437px移動することを再現。指を10px動かしただけで注釈のy座標が約197から-505へ飛んだ。注釈数は1件のままで、削除ではなく表示外への移動だった。

ポインター操作中は修正欄の同期と選択操作欄の更新を保留し、指を離してから表示を更新する。「書き込む」を開くときは選択・修正から始め、前の入力ツールや対象選択を持ち越さない。対象選択だけで削除ボタンを強調表示しない。削除の確認・取消・Undoは維持する。

同じ再現操作でPDFの位置がタッチ中に変わらず、10pxの指移動に相当する量だけ注釈が移動することを確認。回帰テストに実タッチイベントによるドラッグと書き込む再開時の注釈不変を追加。iOS/Android実機は未確認。

「書き込む」では既存の書き込みを直接タップすると、追加ツール中でも選択・修正を優先する。空白への入力は従来どおり。選択ツールを押さず、文字ツール中に既存文字をタップしても注釈が増えず、修正欄から文字を編集できることを検証する。
